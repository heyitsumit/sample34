# Beacon Build Instructions

## Autonomous Execution & Verification

When working on this project, perform any action that can be completed autonomously without asking the user for unnecessary confirmation.

- Start the development server and required local tools.
- Install required dependencies when appropriate.
- Inspect the project structure and relevant files.
- Run the application locally.
- Verify responsive behavior on desktop, tablet, and mobile.
- Check for overlap, collision, broken spacing, alignment, sizing, overflow, and responsive failures.
- Run lint, type-check, build, and tests when available.
- Debug and fix issues found during verification.
- Re-run verification after fixes.
- Make reasonable implementation decisions without repeatedly asking when intent is clear.

Do not stop after writing code when verification can be performed locally.

## Design Authority

The project's supplied gpt-taste SKILL.md is the design authority for visual/UI decisions. Follow its AIDA structure, deterministic design selection, wide 2–3 line hero rule, dense bento requirements, GSAP/ScrollTrigger motion requirements, typography constraints, spacing rules, label bans, and pre-flight design plan.
